# STM32 开发环境搭建技术文档

# 1. 文档概述

# 1.1 文档目的

本文档详细描述 STM32 开发环境的搭建流程，包括开发工具的选型、安装步骤、环境配置及验证测试，旨在为开发人员提供清晰、可操作的指导，确保快速完成开发环境的部署并投入项目开发。

# 1.2 适用范围

本文档适用于首次搭建 STM32 开发环境的开发人员，也可作为现有环境维护、升级的参考资料。适用的 STM32 系列芯片涵盖主流型号（如 STM32F103、STM32F407、STM32L4 系列等），操作系统支持 Windows 10/11（64 位）。

# 1.3 开发工具选型

本次搭建推荐使用 “Keil MDK-ARM + ST-Link 调试器” 的组合，该组合具有工具成熟稳定、社区资源丰富、调试功能完善等优势，具体工具清单如下：

  • 集成开发环境（IDE）：Keil MDK-ARM V5.38a（支持最新 STM32 芯片包）

  • 调试器：ST-Link V2（或 V2-1、V3，用于程序下载与在线调试）

  • 芯片支持包（CMSIS）：针对目标 STM32 系列的专用支持包（如 STM32F1xx、STM32F4xx）

  • 驱动程序：ST-Link 调试器 USB 驱动、串口驱动（如需串口通信）

# 2. 环境搭建前置准备

# 2.1 硬件准备

  • STM32 开发板（如 STM32F103C8T6 最小系统板）

  • ST-Link V2 调试器（带 USB-A 接口和 20Pin/10Pin 调试接口）

  • USB 数据线（2 条：一条连接 ST-Link 与电脑，一条连接开发板与电脑，可选）

  • 杜邦线（若干，用于 ST-Link 与开发板的连接，如无板载调试接口时）

# 2.2 软件准备

提前下载以下软件安装包，建议保存至无中文路径的文件夹（如 D:\STM32_Tools）：

  • Keil MDK-ARM V5.38a 安装包：从 Keil 官网（https://www.keil.com/download/product/）下载，需注册账号（免费注册）

  • ST-Link 驱动：从 ST 官网（https://www.st.com/en/development-tools/st-link-v2.html）下载 “ST-Link/V2 USB driver”

  • STM32 芯片支持包：Keil 官网下载对应系列（如 STM32F1xx）的支持包，或后续在 Keil 软件内在线安装

  • 串口调试工具（可选）：如 SecureCRT、SSCOM、Putty 等，用于查看串口输出信息

# 3. 具体搭建步骤

# 3.1 安装 Keil MDK-ARM V5

  1. 双击下载的 Keil MDK-ARM 安装包（如 MDK538a.exe），弹出安装向导，点击 “Next”。

  2. 勾选 “Accept the terms of the license agreement”（接受许可协议），点击 “Next”。

  3. 选择安装路径（建议默认，或自定义无中文路径，如 C:\Keil_v5），点击 “Next”。

  4. 填写用户信息（Name、Company 可任意填写），点击 “Next”，开始安装（过程约 5-10 分钟，取决于电脑配置）。

  5. 安装完成后，弹出 “Pack Installer” 窗口（Keil 软件的包管理器），暂时关闭该窗口（后续用于安装芯片支持包），点击 “Finish” 完成安装。

  6. 首次启动 Keil 软件，会提示 “License Management”（许可证管理），此时可选择 “Cancel”（后续激活或使用评估版，评估版支持代码大小限制，足够入门开发）。

# 3.2 安装 STM32 芯片支持包

芯片支持包是 Keil 识别 STM32 芯片的核心文件，需根据目标芯片型号安装对应包，步骤如下：

  1. 打开 Keil MDK 软件，点击工具栏中的 “Pack Installer” 图标（或依次点击 “Project” -> “Manage” -> “Pack Installer”），启动包管理器。

  2. 在 Pack Installer 窗口中，切换至 “Devices” 选项卡，在左侧芯片系列列表中找到目标系列（如 “STMicroelectronics” -> “STM32F1xx”）。

  3. 右键点击对应芯片型号（如 “STM32F103”），选择 “Install”，包管理器会自动下载并安装对应的支持包（包括 CMSIS 核心文件、外设驱动等）。

  4. 安装完成后，关闭 Pack Installer 窗口，返回 Keil 主界面。

# 3.3 安装 ST-Link 调试器驱动

ST-Link 调试器需安装 USB 驱动后，电脑才能识别，步骤如下：

  1. 解压下载的 ST-Link 驱动安装包（如 en.stsw-link009.zip），进入解压后的文件夹。

  2. 将 ST-Link V2 调试器通过 USB 数据线连接至电脑，电脑会自动检测新硬件并尝试安装驱动。

  3. 若驱动未自动安装成功，右键点击 “此电脑” -> “管理” -> “设备管理器”，在 “其他设备” 中会看到带有黄色感叹号的 “ST-Link” 设备。

  4. 右键点击该设备，选择 “更新驱动程序” -> “浏览我的计算机以查找驱动程序软件”，选择解压后的 ST-Link 驱动文件夹，点击 “下一步”，完成驱动安装。

  5. 驱动安装成功后，在设备管理器的 “通用串行总线设备” 中会显示 “ST-Link USB Debug”，表示识别成功。

# 3.4 连接 ST-Link 与 STM32 开发板

根据开发板是否带有板载 ST-Link 接口，分为两种连接方式：

# 3.4.1 板载 ST-Link 接口（如 STM32F4Discovery 开发板）

直接用 USB 数据线连接开发板的 “ST-Link” USB 接口与电脑即可，无需额外连接杜邦线。

# 3.4.2 非板载 ST-Link 接口（如 STM32F103C8T6 最小系统板）

# 4. 环境验证测试

通过创建一个简单的 “LED 闪烁” 项目，验证开发环境是否正常工作，步骤如下：

# 4.1 创建新项目

  1. 打开 Keil MDK 软件，点击 “Project” -> “New μVision Project”，选择项目保存路径（无中文），输入项目名称（如 “STM32F103_LED”），点击 “Save”。

  2. 在弹出的 “Select Device for Target” 窗口中，选择目标芯片型号（如 “STMicroelectronics” -> “STM32F103C8”），点击 “OK”。

  3. 弹出 “Manage Run-Time Environment” 窗口，勾选以下组件（基础必备组件）：

  • CMSIS -> Core（核心组件，提供芯片底层驱动）

  • Device -> Startup（启动文件，芯片上电初始化）

  • Device -> StdPeriph Drivers -> GPIO（GPIO 外设驱动，控制 LED）

  1. 点击 “OK”，完成项目创建，此时项目窗口中会显示 “Sources Group 1”（源文件组）和 “Headers Group 1”（头文件组）。

# 4.3 项目配置与编译

  1. 点击工具栏中的 “Options for Target” 图标（或右键点击 “Target 1” -> “Options for Target 'Target 1'”），打开项目配置窗口。

  2. 切换至 “Target” 选项卡，确认 “晶振频率（Xtal (MHz)）” 设置为 12（STM32F103 默认外部晶振 12MHz）。

  3. 切换至 “Debug” 选项卡，在 “Debugger” 下拉列表中选择 “ST-Link Debugger”，点击右侧的 “Settings” 按钮。

  4. 在 “ST-Link Debugger Settings” 窗口中，切换至 “SWDIO” 选项卡，确认 “Interface” 为 “SWD”，点击 “OK” 返回上一级窗口。

  5. 勾选 “Debug” 选项卡中的 “Load Application at Startup”（启动时加载程序），点击 “OK” 完成配置。

  6. 点击工具栏中的 “Build” 图标（或按 F7），进行项目编译，编译完成后，底部 “Build Output” 窗口会显示 “0 Error (s), 0 Warning (s)”，表示编译成功，同时生成.hex 格式的可执行文件。

# 4.4 程序下载与运行

  1. 确认 ST-Link 与开发板连接正常，开发板电源已接通（可通过 ST-Link 的 3.3V 供电，或单独给开发板供电）。

  2. 点击工具栏中的 “Download” 图标（或按 Ctrl+F5），将编译生成的程序下载至 STM32 芯片中，下载完成后，底部窗口会显示 “Download Complete”。

  3. 点击工具栏中的 “Run” 图标（或按 F5），运行程序，此时开发板上的 LED 应开始闪烁，说明开发环境搭建成功，程序运行正常。

# 5. 常见问题及解决方法

# 5.1 Keil 无法识别 ST-Link 调试器

  • 原因：ST-Link 驱动未安装成功，或 USB 连接松动。

  • 解决方法：重新安装 ST-Link 驱动；更换 USB 数据线或 USB 接口；检查 ST-Link 与开发板的 GND 引脚是否连接正常（共地是通信的基础）。

# 5.2 项目编译报错 “undefined reference to xxx”

  • 原因：缺少相关驱动文件（如启动文件、外设驱动文件），或文件未添加到项目中。

  • 解决方法：在 “Manage Run-Time Environment” 窗口中重新勾选对应的组件（如 CMSIS、GPIO 驱动）；检查源文件是否已添加到 “Sources Group 1” 中，若未添加，右键点击文件组添加对应文件。

# 5.3 程序下载失败，提示 “Cannot connect to target”

  • 原因：ST-Link 与开发板的 SWD 接口连接错误；开发板电源未接通；芯片被锁死。

  • 解决方法：重新核对 SWDIO、SWCLK、GND、3.3V 引脚的连接；检查开发板电源；若芯片被锁死，可通过 ST-Link 的 “Full Chip Erase” 功能擦除芯片后重新下载。

# 5.4 LED 不闪烁，程序运行无反应

  • 原因：LED 引脚配置错误（如引脚号写错）；延时函数延时时间过短或过长；程序未正常运行。

  • 解决方法：核对 LED 连接的引脚与代码中配置的 GPIO 引脚是否一致；调整延时函数的参数（如增大 Delay (1000000)）；通过 Keil 的单步调试（按 F11）检查程序是否执行到 LED 控制语句。
