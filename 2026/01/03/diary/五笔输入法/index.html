# 五笔输入法

<img src="https://gitee.com/fangcongss/blogImages/raw/master/blog/image-20260103133107745.png" alt="image-20260103133107745" />

  1. 找字根：先定区后定笔画数量【（巡 53 V 45P）--> vp --> "巡" 巡】 【（横）14S 15A 25M -->SAM --->"横" 】
  2. 拆解汉字：将一个完整的汉字拆分为不同的字根和笔画
    1. 按书写顺序拆分
    2. 能连不交
    3. 兼顾直观
  3. 汉字分类
    1. 键名汉字，即每个按键上的第一个字。输入规则：连按讲明所在的按键四下。
    2. 成字字根，是在字根表中除了键名之外能看到的汉字。输入规则：所在键 + 首笔笔画 + 次笔笔画 + 末笔笔画
    3. 键外字，是除了键名汉字和成字字根外的其他汉字。输入规则：第一字根 + 第二字根 + 第三字根 + 最后一个字根
    4. 另外，有些汉字的字根少于四个，那该如何输入呢？这就需要我们先了解汉字的结构。汉字的结构不外乎三种：** 左右结构、上下结构、杂合结构（只要不是属于前两种类型的都是杂合）。** 由于这些汉字字根不足 4 个，需要补打末笔识别码。所谓末笔识别码是首先判断最后一笔是什么？再判断汉字是什么结构？
  4. 打词组：
    1. 二字词组需要取每个字的前两个字根
    2. 三字词组需要取前两个字的第一个字根，第三个字的前两个字根
    3. 四字词组需要取每个字的第一个字根
    4. 多字词组需要取前三个字的第一个字根和最后一个字的字根
